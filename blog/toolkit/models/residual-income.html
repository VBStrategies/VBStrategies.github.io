Model · Intrinsic value

Residual income

Values equity as book value plus the present value of the returns above the cost of equity. It gives the same answer as the dividend model, but recognises the value much earlier.

Best forBanks, insurers, firms with no dividends
Main inputsBook value, ROE, cost of equity, fade
EffortModerate: needs clean accounting
On this page The idea · Clean surplus · Versions · Economic profit · Accounting adjustments · Worked example · When it misleads · Common mistakes · In the strategy · Sources

1 · The idea

The residual income model starts from the balance sheet. A shareholder has already put book value into the company; the question is how much more than that the company will earn. Profit only creates value if it exceeds what shareholders could earn elsewhere at the same risk, the cost of equity. The excess is residual income.

Residual incomet = Net incomet − Cost of equity × Book valuet−1 = (ROEt − Cost of equity) × Book valuet−1
Value of equity = Book value0 + Σ Residual incomet ÷ (1 + Cost of equity)t

A company that earns exactly its cost of equity is worth its book value. One that earns more is worth more, one that earns less is worth less, however large its profits look.

2 · Why it gives the same answer as dividends

The model rests on the clean surplus relation: book value changes only through earnings and dividends.

Book valuet = Book valuet−1 + Net incomet − Dividendst

When this holds, residual income valuation is a rearrangement of the dividend discount model, and the two always give the same value. Ohlson (1995) set out this link formally. The difference is timing: the residual income model recognises value through book value today and excess returns soon after, while the dividend model leaves most of the value in a distant terminal value.

In practice clean surplus is often broken. Items booked in other comprehensive income (currency translation, pension remeasurements, some changes in fair value) change book value without passing through net income. They must be added back or forecast, or the model drifts away from the dividend value.

3 · The versions: how long excess returns last

The versions differ in what happens to residual income after the explicit forecast, which is the key judgement in the model:

VersionAssumption after year TFormula
Single-stageConstant ROE and growth from todayP/B = 1 + (ROE − r) ÷ (r − g)
Multistage, stable residual incomeResidual income keeps growing at g after year TTVT = RIT+1 ÷ (r − g)
Multistage with fadeResidual income declines each year by a persistence factor ω between 0 and 1TVT = RIT+1 ÷ (1 + r − ω)
Competitive equilibriumROE falls to the cost of equity after year TTVT = 0

The persistence factor comes from the CFA Institute curriculum. A value close to 1 suits companies with lasting advantages; a value close to 0 suits companies whose high returns will be competed away quickly. Competitive pressure is the normal case, so assuming that residual income grows forever needs a reason.

4 · The enterprise version: economic profit and EVA

Economic profitt = (ROICt − WACC) × Invested capitalt−1
Enterprise value = Invested capital0 + Σ Economic profitt ÷ (1 + WACC)t

The same idea at the level of the whole firm. McKinsey calls it the economic profit model and treats it as equivalent to the enterprise DCF; Stern Stewart's EVA is a branded version with specific accounting adjustments. It is useful for operating companies because it shows each year whether growth is creating value: growth only adds value when ROIC exceeds WACC.

5 · Accounting adjustments

  • Other comprehensive income: forecast it, or the clean surplus relation fails.
  • Goodwill and intangibles: acquired goodwill raises book value and lowers ROE; internally built brands and research are not on the balance sheet at all and make ROE look too high.
  • Buybacks: reduce book value; ROE rises without any change in the business.
  • Banks and insurers: use tangible book value, and check that loan loss provisions and reserves are neither too low nor too generous.
  • One-off items: remove them from the ROE used for forecasting.

7 · When to use it, and when it misleads

Use whenBanks and insurers; companies with no dividends or negative free cash flow but positive, transparent earnings; when the terminal value would otherwise dominate.
Misleads whenBook value is far from economic value (brands, software, research); accounting is aggressive; large items bypass the income statement.

8 · Common mistakes

  • Ignoring other comprehensive income, so the result no longer reconciles with dividends.
  • Assuming excess returns last forever without a reason.
  • Using book value after a large buyback or write-off without adjustment.
  • Mixing the equity version (ROE, cost of equity) with the enterprise version (ROIC, WACC).
  • Using end-of-year book value instead of the opening value to compute the capital charge.

9 · Where it fits in the strategy

In VB Europe Strategic residual income is the primary model for any bank or insurer, with the dividend model and price/book against ROE as cross-checks. Its enterprise version, economic profit, is used for operating companies to test whether forecast growth really creates value.
